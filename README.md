# 🚀 JavaScript 基础语法 Skill Demo

## 📖 Skill 介绍
这是一个JavaScript入门级基础语法Skill，覆盖前端开发必备的核心语法知识点，适合新手学习和复习。

## ✅ 包含的核心知识点
| 模块 | 语法内容 | 作用 |
| :--- | :--- | :--- |
| 变量声明 | `var`/`let`/`const` | 存储数据，区分传统与ES6声明方式 |
| 数据类型 | 字符串/数字/布尔/数组/对象/undefined/null | JS基础数据类型全覆盖 |
| 函数 | `function greet(name)` | 封装可复用的逻辑，实现参数传递与返回值 |
| 条件语句 | `if...else` | 根据条件执行不同代码分支 |
| 循环语句 | `for` 循环 | 遍历数组，批量执行重复操作 |
| 控制台输出 | `console.log()` | 调试代码、打印运行结果 |

## 🚀 运行方式
1.  直接用浏览器打开 `0415.html` 文件
2.  按下 `F12` 打开浏览器开发者工具，切换到「Console（控制台）」标签
3.  即可看到代码的运行输出结果

## 🧪 测试与扩展

- 修改`arr`数组的内容，测试循环遍历效果
